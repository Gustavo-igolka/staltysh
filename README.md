# Бункер — одиночная стрелялка с рейтингом

Этап 1–2: каркас, вход и сохранения, меню (Главное, Инвентарь, Магазин, Бартер, Боевой пропуск, Донатный магазин, Настройки).
Этап 3: открытый мир «Болото» — движение, стрельба, перезарядки, живые отряды с ИИ, споты с добычей, осада аномальной установки, миникарта. Рейтинг — дальше, кнопка пока показывает «скоро».

## Запуск

Игра — обычные файлы без сборки. Открывать через сервер (ES-модули не работают с `file://`):
GitHub Pages: репозиторий → Settings → Pages → Deploy from a branch → `main` / root. Файлы должны лежать так, чтобы `index.html` был в корне.

Локально: `python3 -m http.server` в этой папке и открыть `http://localhost:8000`.

## Подключение Supabase

1. Supabase → SQL Editor → вставить и выполнить `supabase/schema.sql` (таблицы с префиксом `shooter_`, с ними другие приложения в проекте не пересекаются).
2. Project Settings → API → скопировать Project URL и anon key в `js/config.js`.
3. Пока ключи пустые, игра работает локально: прогресс хранится в браузере, входа и рейтинга нет.

## Структура

```
index.html
css/       base.css (основа, кнопки, шторки), menu.css (экраны)
js/
  main.js      старт: вход → загрузка сохранения → каркас
  config.js    ключи Supabase
  core/        state (единое состояние), events, dom (сборка DOM), util, session
  data/        items (предметы, ресурсы, магазин), player (константы персонажа и статы брони), enemies (виды врагов и их ИИ-характеристики), barter, pass — здесь правится баланс
  game/        inventory (сетка+вес, слоты, потеря при смерти), stats (итоговые характеристики), economy (покупка/продажа/бартер), pass, input (ввод), session (игровая сессия)
    sim/       симуляция открытого мира: world (движение/бой/объекты), ai (патруль/погоня/атака/бегство/осада), pathfind (A* в обход препятствий), spots (точки интереса, респаун, добыча), siege (осада установки)
    render/    рисование мира и миникарты
  net/         supabase, auth, save, sync (автосохранение)
  ui/          экраны и общие элементы
supabase/schema.sql
```

## Режим разработчика

Настройки → «Режим разработчика»: +деньги, +хромогрониты, +опыт пропуска, ресурсы и хлам на склад, сломать/починить всё снаряжение. В открытом мире добавляет кнопки урона по игроку (для проверки формулы запаса), переключатель меток точек интереса, кнопку «Осада разлома рядом» (запускает осаду установки для проверки без похода к реальному разлому), и кладёт мир в `window.__world` (и рендерер в `window.__renderer`) для отладки из консоли браузера.

## Открытый мир (этап 3)

- Карта «Болото» (`js/data/maps/swamp.js`) — правится вручную посимвольно (см. комментарий в начале файла). Бункер на самом юге. Редкость ресурсов зависит не от координаты внутри карты, а от того, насколько локация в целом далека от бункера в масштабе всего мира — Болото как первая локация целиком серое (`bands`). Прикопы и разломы появятся на следующих, более дальних локациях (нужна синяя/фиолетовая редкость). Переход на север пока заблокирован.
- Управление: на телефоне — стик слева двигает, стик справа только задаёт направление прицела (больше не стреляет сам), отдельная круглая кнопка «Огонь», плюс кнопки перезарядки, смены оружия, инвентаря (🎒) и карты (🗺); на компьютере — WASD/стрелки, мышь целится и стреляет ЛКМ (или пробел), R — перезарядка, Q — смена оружия, 1/2 — выбор оружия, E/F — взаимодействие, I — инвентарь, M — карта, Esc/P — пауза. Инвентарь и карта открываются прямо поверх игры (оверлей, бой ставится на паузу) — выходить в бункер для этого не нужно.
- Бой: урон по формуле запаса, множитель по мутантам, кровотечение и «остановка» как шансовые эффекты снайперской ветки, деревья и руины останавливают пули, прочность оружия падает за выстрел и приводит к клину.
- Заход только с оружием в руках (основным или доп.), выход — через люк бункера или паузу (там же кнопка выхода в бункер, доступна только у люка, и кнопка настроек).
- Враги (`js/data/enemies.js`, ИИ — `js/game/sim/ai.js`): отряды мутантов (кабаны/псы, ближний бой) и людей (бандиты/военные, дальний бой с разбросом и репозицией) патрулируют свою зону, преследуют игрока в прямой видимости, дальнобойные держат дистанцию и обходят препятствия по пути (A*, `pathfind.js`) при потере видимости вместо движения напролом, мутанты и ближний бой отступают при низком HP и возвращаются. У каждого НПС характеристики отряда ±6% случайного разброса. Старые неподвижные мишени (`dummy`) остались как учебный полигон.
- Точки интереса (`js/game/sim/spots.js`): споты мутантов/людей заселены сразу при заходе в мир; зачистка роняет ящик (хлам + бартерные ресурсы любого типа на редкость зоны); отряд разбредается на 3–5 клеток от точки, когда она респаунится. Респаун (90 сек) идёт, только пока точка НЕ видна на экране — на карте или вдалеке это не считается.
- Осада разлома (`js/game/sim/siege.js`): 8 мутантов спавнятся по одному раз в 7 секунд и ломают установку (50 ХП, прочнее обычного — иначе осада кончается раньше, чем успеешь отреагировать); награда пропорциональна числу мутантов, убитых до того, как установка сломана (8/8 — полный лут, 0 — ничего).
- Миникарта/полная карта (M, 🗺): показывает всю карту, бункер, точки интереса (цвет — живой спот/зачищенный) и позицию игрока.
- Зоны заражения (`world.js`, зоны заданы в `js/data/maps/swamp.js` → `zones`): пока игрок внутри зоны и защита (rad/bio/psi/temp из брони) не перекрывает её уровень, копится шкала заражения этого типа (0–100%); вне зоны шкала выводится (cleanseRate — для радиации/био/пси, burnRemoval — для температуры); на 100% тикает урон по здоровью, отдельно от обычного урона и брони. Болото — первая локация, поэтому на ней только два лёгких пятна биозаражения 1 уровня (топи), полностью блокируются «Защитным комбинезоном» (bio 100). HUD показывает полоску активного заражения и подсвечивает критическое состояние.

## Что уже работает

- Слоты персонажа: броня, оружие, доп. оружие, рюкзак. Инвентарь вылазки — большая сетка 8×10, ограничивает вес (50 кг базово + броня + рюкзак/сумка), а не место. Склад бункера отдельно.
- Принадлежность вещей (иконки 🔒/🛡 в инвентаре): 🔒 — личная непередаваемая вещь (сделана из бартера, с боевого пропуска, сюжетная — снаряжение и бартерные ресурсы); 🛡 — личная передаваемая (с аукциона/донатного ящика, пока не реализовано); без иконки — не личная (патроны, медицина, хлам), теряется при смерти и будет передаваемой, когда появится обмен. При смерти в открытом мире инвентарь вылазки теряется, но личные непередаваемые вещи (кроме бартерных ресурсов — они расходуются как ресурс) возвращаются на склад бункера, а не пропадают навсегда.
- Магазин: патроны, аптечки, установки, металлоискатель (покупка идёт в инвентарь, лишнее — на склад); продажа хлама.
- Бартер: вкладка → подраздел → ветка (Оружие, Доп. оружие, Сумки, Броня; броня по классам: боевая, научная, комбинированная). Покупка первого слабого предмета за деньги. Новые ветки добавляются в `js/data/barter.js`.
- Характеристики персонажа: база без брони (50 кг, 100 хп и т. д.) + броня и сумка. Панель «Характеристики» в инвентаре. Формула запаса: (здоровье + защита) × живучесть.
- Боевой пропуск: 25 уровней, награды, скидки, красная вещь на 25 уровне (выдача — с углублённым бартером).
- Оружие и доп. оружие: один набор характеристик (урон, скорострельность, магазин, дальность, две перезарядки, доставание, скорость в руках) плюс необязательные (кровотечение, остановка, множитель по мутантам). Прочность есть у оружия и брони: сломанная вещь не даёт характеристик, но остаётся мёртвым грузом (ремонт — позже). Рюкзаки и сумки: прибавка к весу, необязательные скорость и живучесть.
- Автосохранение: браузер всегда + облако при входе в аккаунт.
